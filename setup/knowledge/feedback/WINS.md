# WINS — real-world results worth learning from

> Log anything that WORKED with real numbers: a listing that sells, an email with a great open
> rate, a post that pulled signups, a set that filled the floor. These entries become tomorrow's
> exemplars: periodically promote the best into `domains/<domain>/examples/` (replace the
> generic templates with proven winners).
>
> Entry takes 2 minutes. Or just tell any agent: "log this win."

## Template

```
### YYYY-MM-DD — <one-line what>
- Domain: <marketing / ecommerce / ...>
- Artifact: <link or path to the actual deliverable>
- Result: <the numbers: CTR, sales, opens, attendance...>
- Why we think it worked: <1-3 bullets>
- Promote to examples/? <yes/no — if yes, do it>
```
