Write this month's issue of a 2-person studio's newsletter ("The Workbench", ~600 words,
goes to 830 subscribers: freelancers and small SaaS founders). FIXED evaluation brief:
only the material below; no invented events, numbers, or reader mail.

THIS MONTH'S RAW MATERIAL (fixed):
- Main lesson: we shipped a client's shop redesign 9 days late because we accepted "just one
  more small change" four times without re-scoping. New rule we adopted: every change request
  after sign-off gets a written 2-line impact note (cost in days + what moves) before we say yes.
- Small win: our invoice-reminder SaaS pilot hit 37 active users; average payment time dropped
  11 days.
- Tool note: we started using a shared "definition of done" checklist per project; cut our
  handoff bugs roughly in half (from ~6 to ~3 per project over the last 4 projects).
- One recommendation: the book "The Mom Test" — because it fixed how we run discovery calls.
- CTA for this issue (exactly one): reply with the change-request story that burned you —
  the best one gets dissected (anonymously) next issue.

Deliverable: subject line (≤ 45 chars) + preview text + the full issue, written in a personal,
plain voice — one core idea (scope creep is a consent problem, not a client problem), the win
and tool note as short sidebars, no hard sell.
