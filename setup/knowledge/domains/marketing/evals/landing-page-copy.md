Write the complete landing page copy (headline, subhead, section-by-section body, CTA blocks,
FAQ of 4 questions) for the following product. This is a FIXED evaluation brief: use ONLY the
facts below; if a fact you need is missing, state it as an explicit assumption in one line —
never invent numbers, testimonials, or customers.

FACTS (fixed):
- Product: Mahnwerk — a web app that automatically sends polite, legally compliant payment
  reminders (Zahlungserinnerung → 1. Mahnung → 2. Mahnung) for German freelancers' unpaid invoices.
- Audience: German freelance designers and developers, 1-person businesses, 10–40 invoices/month,
  who chase payments by hand on evenings and hate the awkwardness ("Ich will nicht nerven, aber…").
- Proofs available: pilot with 37 freelancers — average 11 days faster payment; 92% of reminders
  needed no manual edit; quote from pilot user Jonas R., web developer: "Ich habe seit drei
  Monaten keine einzige Mahnung mehr selbst geschrieben."
- Offer: 14-day free trial, no credit card; then 12 €/month flat.
- Primary conversion action: start the free trial.
- Measurable objective for the page: trial signups from 25/month to 60/month by October 31.
- Tracking: all outbound links carry UTMs (utm_source, utm_medium, utm_campaign=mahnwerk-launch).
- Language: write the page in English (the German market copy is a later task); keep the two
  German pilot-quote fragments verbatim.

Deliverable: the full page copy in publish order, with one line per section naming its job.
