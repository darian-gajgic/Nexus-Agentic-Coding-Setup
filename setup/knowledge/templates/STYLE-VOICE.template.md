# STYLE & VOICE — how everything we publish sounds

> Agents: apply this to every outward-facing text (site, listings, emails, posts, proposals).
> Domain playbooks govern structure and craft; this file governs voice. Per-brand overrides at
> the bottom win over the defaults.

## Voice defaults (until onboarding refines them)

| Trait | Do | Don't |
|---|---|---|
| **Direct** | Lead with the point. Short sentences. | Warm-up paragraphs, throat-clearing intros |
| **Concrete** | Numbers, examples, specifics ("ships in 2 days") | Abstractions ("fast delivery solutions") |
| **Honest** | Plain claims we can back | Hype, superlatives, invented social proof |
| **Human** | Write like one competent person talking to another | Corporate we-speak, buzzwords |
| **Helpful-first** | Give value before asking | Pitch-first everything |

- Reading level: aim for simple, clear sentences (a 14-year-old could follow) — even for expert
  audiences. Experts prefer clarity too.
- Active voice. "We build X", not "X is built by us."
- One idea per paragraph. One CTA per piece.

## Forbidden (AI-slop kill list — instant rewrite if these appear)

`delve`, `unleash`, `unlock the power of`, `revolutionize`, `game-changer`, `in today's
fast-paced world`, `look no further`, `elevate your`, `seamless(ly)` (unless literally about seams),
`cutting-edge`, `robust solutions`, `we're passionate about`, `it's important to note`,
`furthermore/moreover` chains, em-dash overuse, three-adjective pileups ("fast, reliable, and
powerful"), rhetorical-question openers ("Ever wondered…?"), fake urgency without a real deadline.

## Formatting conventions

- Headlines: benefit or specific claim, never a pun that hides the topic.
- Bullets: parallel grammar, ≤2 lines each, no bullet-walls (max ~6 in a row).
- Bold sparingly — only decision-relevant phrases.
- Emojis: {{FILL: policy per channel — default: none in email/site, sparing on social}}.
- Numbers: digits ("7", not "seven"); currencies and units explicit.
