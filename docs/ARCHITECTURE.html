Dispatch state machine

tasks.dispatch_state — orthogonal to the kanban board

none→ queued→ dispatching→ streaming→ finalizing→ completed
exits from any active state: failed blocked_quota blocked_budget cancelled

Heartbeat stale >90s → the lane resumes via the orphan ladder: active = wait & refresh · finished = harvest from session history · dead = supersede with a continue-turn. Runaway only at 2× the turn cap; blocked states self-clear and retry. completed finalizes to kanban review (high-stakes) or done.
